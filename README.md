# Englingo

Личный курс английского в две ступени по 45–60 минут в день. Прокачивает грамматику, чтение, письмо и аудирование — то, чего не даёт Duolingo. Приложение — Vue 3 + дизайн-система [Aura](https://github.com/ilomee/aura), PWA с интервальным повторением карточек; работает на GitHub Pages и без сети. Устроено так же, как `../francais`.

| Ступень | Модули | Учебник | Экзамен-ориентир |
|---|---|---|---|
| B1 → B2 | `00`–`16`, ~16 недель | Oxford Practice Grammar Intermediate (Eastwood) | Cambridge B2 First |
| B2 → C1 | `c1-00`–`c1-18`, ~17 недель | Oxford Practice Grammar Advanced (Yule) + Supplementary Exercises | Cambridge C1 Advanced |

## Запуск

```bash
npm install
npm run dev                  # http://localhost:5173/englingo/
```

Курс — статическое приложение без сервера: контент собирается в JSON при сборке, ответы проверяются в браузере. Прогресс хранится в IndexedDB этого браузера (или установленного приложения); на странице «Прогресс» его можно сохранить в файл и загрузить на другом устройстве.

### Прогресс из Go-версии

Раньше Englingo был сервером на Go и хранил прогресс в `~/.englingo/progress.db`. Чтобы перенести его:

```bash
node scripts/import-go-progress.ts           # → englingo-progress.json
```

Затем «Прогресс» → «Загрузить из файла».

## На телефоне

Сайт — PWA: в Safari «Поделиться → На экран „Домой“», в Chrome «Установить приложение». После первого запуска весь курс работает без сети: уроки, упражнения и карточки лежат в кеше. Новая версия курса скачивается в фоне, и приложение предлагает перезагрузиться.

Тема по умолчанию светлая; кнопка ◐ в шапке переключает на тёмную и запоминает выбор.

## Сайт на GitHub Pages

1. Создай **публичный** репозиторий на GitHub (Pages бесплатен только для публичных) и запушь проект.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Каждый пуш в `main`/`master` запускает `.github/workflows/pages.yml`: типы и тесты → `validate` → сборка → публикация на `https://<user>.github.io/<repo>/`.

Локально, как на Pages:

```bash
npm run build -- --base=/englingo/
npm run preview              # http://localhost:4173/englingo/
```

Pages не умеет отдавать одну страницу на все адреса, поэтому сборка кладёт рядом с `index.html` его копию `404.html`: прямая ссылка на урок открывает приложение, а роутер показывает нужную страницу.

## Как заниматься

Модули 1–11 — основная грамматика, 12–15 — предлоги, фразовые глаголы, местоимения/прилагательные/наречия и словообразование (Part 3 экзамена). Все 153 юнита OPG Intermediate (Eastwood) привязаны к урокам — список в `content/book.yaml`.

Ступень C1 устроена так же: входной тест `c1-00`, 17 тематических модулей по главам OPG Advanced (+ модуль Use of English), итоговый тест `c1-18`. Письмо — 220–260 слов в жанрах C1 Advanced. Разделы книги — в `content/book-advanced.yaml`, у каждого раздела есть страница в Supplementary Exercises.

Начни с **модуля 0** — входного теста. Страница «Прогресс» покажет слабые темы. Потом иди по модулям по порядку: один модуль — одна неделя.

| День | Что делать |
|---|---|
| Пн–Ср | урок грамматики (в некоторых модулях их четыре): теория, затем 3–4 упражнения. Урок засчитывается, если в каждом упражнении правильно от 80 %. В конце урока указаны юниты Oxford Practice Grammar — их упражнения делай в книге, ключи на с. 386 |
| Чт | чтение: текст уровня B2 и вопросы в формате B2 First |
| Пт | письмо: эссе, письмо, статья, отзыв или отчёт на 140–190 слов |
| Сб | аудирование: две записи в формате B2 First Listening (Part 1–4) и диктант на грамматику недели |
| Каждый день | 10 минут карточек во вкладке «Повторение» (Duolingo — по желанию сверху) |

В конце курса — **модуль 16**, итоговый тест в формате B2 First. Его результаты по темам встанут в таблицу рядом с входным тестом.

Проверка прощает регистр, лишние пробелы, пунктуацию и сокращения: `I've` = `I have`, `can't` = `cannot`, `'d` = `had` или `would`.

### Аудирование

- **Свои записи.** Интервью, диалоги и монологи курса озвучены нейронными голосами с разными акцентами — британскими, американским, австралийским и ирландским, как на экзамене. Текст наш, поэтому после проверки ответов открывается точная расшифровка.
- **Живые голоса.** Фразы диктантов — и из записей носителей Tatoeba под открытыми лицензиями (CC BY, CC BY-SA); автор и лицензия — под плеером.
- **Внешние записи** (BBC Learning English, British Council) не копируются: кнопка открывает их на сайте, вопросы — наши.
- Записи кешируются, когда их послушаешь, и потом доступны без сети.

### Письмо и Claude

1. **Самопроверка.** После текста нажми «Готово — проверить себя», пройди чек-лист и сохрани работу. Откроется образец ответа.
2. **Разбор с Claude.** Кнопка «Скопировать для Claude» кладёт в буфер готовый запрос: задание, твой текст и что проверить (исправления, ошибки с объяснением по-русски, оценка по шкалам Cambridge Writing). На телефоне есть «Поделиться…» — сразу в приложение Claude.
3. **Копия текста.** «Скачать .md» сохраняет текст с заданием и самопроверкой одним файлом — его можно отдать Claude Code.

## Устройство

```
build/content.ts      загрузка и проверка курса: модули, уроки, упражнения, карточки (YAML + Markdown)
build/markdown.ts     Markdown → HTML с классами Aura, блоки ```quiz
build/compile.ts      индекс курса + по чанку на урок + карточки
build/course-plugin.ts  Vite-плагин: virtual:course, аудио, перезагрузка при правке контента
build/validate.ts     npm run validate
src/course/           логика без Vue: проверка ответов (регистр, пунктуация, сокращения), SM-2,
                      уровни, карточки к повторению, статистика, запрос для Claude
src/stores/           прогресс в IndexedDB (Pinia), тема и ступень в localStorage
src/pages/, src/components/  страницы и компоненты на @ilomee/aura-vue
e2e/                  Playwright: урок целиком, черновики, офлайн, перенос прогресса (телефон и десктоп)
scripts/tts.py        озвучка своих сценариев (edge-tts, 8 дикторов)
scripts/tatoeba.py    пул английских фраз с открытым аудио носителей и русским переводом
scripts/              ещё: перенос прогресса из Go-версии, validate-modules.sh
content/              курс
```

## Автору контента

Формат описан в [CONTENT.md](CONTENT.md).

```bash
npm run dev                                 # курс перечитывается с диска на каждое сохранение
npm run validate                            # проверить весь контент
npm test                                    # юнит- и компонентные тесты
npm run typecheck
python3 -m venv scripts/.venv && scripts/.venv/bin/pip install edge-tts   # один раз
scripts/.venv/bin/python scripts/tts.py      # озвучить новые и изменённые сценарии
python3 scripts/tatoeba.py pool              # собрать scripts/pool.tsv
python3 scripts/tatoeba.py fetch 253673      # скачать запись и получить пункт диктанта
npm run build && npm run e2e                # сборка и сквозные тесты в браузере
```
