Key word transformation — Part 4 экзамена B2 First и, пожалуй, лучший способ проверить, насколько гибко ты владеешь грамматикой. Ты весь курс решал такие задания по отдельным темам; здесь они собраны вместе.

## Формат

Дано предложение и ключевое слово. Нужно закончить второе предложение так, чтобы смысл не изменился:

- использовать **ключевое слово без изменений** (не *said* вместо *SAY*);
- вписать **от 2 до 5 слов**, включая ключевое (сокращения вроде *don't* считаются за два слова);
- не менять ничего в начале и в конце второго предложения.

На экзамене за каждое задание дают до двух баллов: часто ответ состоит из двух «кусков» (например, *was made* + *to*), и за каждый — по баллу. Здесь проверка строже: засчитывается только полностью верный ответ.

## Как решать

1. **Определи тему.** Ключевое слово почти всегда подсказывает конструкцию: *UNLESS* — условие, *SAID* — *be said to*, *DESPITE* — противопоставление, *WISH* — сожаление.
2. **Проверь время.** Самая частая потеря балла — верная конструкция в неверном времени: *is said to be* вместо *is said to have been*.
3. **Посчитай слова.** Больше пяти — ищи более короткую конструкцию.
4. **Перечитай всё предложение целиком.** Оно должно звучать естественно и значить то же, что исходное.

| Ключевое слово | Типичная трансформация |
|---|---|
| SINCE / FOR | *last saw … ago* → *haven't seen … for* |
| USED | *it's not strange any more* → *be / get used to + -ing* |
| CAN'T / MUST | *I'm sure … didn't* → *can't have + V3* |
| WISH | *I regret …* → *wish + Past Perfect* |
| SAID | *People say that …* → *is said to …* |
| DENIED / SUGGESTED | прямая речь → глагол + *-ing* |
| DESPITE | *although* → *despite + сущ. / -ing* |
| NEVER | *never … before* → *Never have I…* |
| BY | *no later than* → *by* + срок |
| UP | *tolerate* → *put up with* |
| SUCH | *so boring that* → *such a boring film that* |
| EXPLANATION | глагол → существительное: *no explanation (as to) why* |
