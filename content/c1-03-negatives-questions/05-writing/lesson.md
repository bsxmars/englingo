Эссе — **обязательное** задание C1 Advanced (Writing, Part 1). Тебе дают тему, три пункта для обсуждения и несколько мнений из «дискуссии». Нужно выбрать **два** пункта из трёх, обсудить их, решить, какой **важнее / эффективнее**, и обосновать выбор. Мнения из задания можно использовать, но своими словами. Объём — 220–260 слов, регистр — формальный или нейтральный.

Это идеальное место для грамматики модуля. Одна инверсия (*Not only does…*, *Rarely do…*) и один риторический вопрос сразу поднимают текст на уровень C1, но злоупотреблять ими нельзя.

## Устройство жанра

- **Введение** обозначает проблему, но не пересказывает задание дословно.
- **Два основных абзаца** — по одному на каждый выбранный пункт: аргумент, пояснение, пример или следствие.
- **Заключение** обязательно отвечает на вопрос задания: какой из двух пунктов важнее и **почему**.
- Третий пункт не обсуждаем — это не ошибка, а требование.
- Никаких заголовков (это не отчёт) и никаких «Dear…» (это не письмо).

## План по абзацам

| Абзац | Что пишем | Объём |
|---|---|---|
| **1. Введение** | Проблема и почему она актуальна; можно риторический вопрос | 2–3 предложения |
| **2. Пункт 1** | Довод, пояснение, пример; уступка *admittedly…* | 4–5 предложений |
| **3. Пункт 2** | Довод, пояснение, пример; сравнение с пунктом 1 | 4–5 предложений |
| **4. Заключение** | Какой пункт важнее и почему; итоговая мысль | 2–3 предложения |

## Полезные фразы

| Функция | Фразы |
|---|---|
| Ввести тему | *It is often argued that… · Few would dispute that… · Why is it that…?* |
| Риторический вопрос | *Is it really surprising that…? · What, then, can be done to…?* |
| Эмфаза инверсией | *Not only does X…, but it also… · Rarely do… · Only when… does… · At no point should…* |
| Уступка | *Admittedly, … · While it is true that…, … · Granted, …* |
| Контраст | *Nevertheless, … · That said, … · By contrast, …* |
| Сравнить и выбрать | *Of the two, … is arguably the more effective, since… · …is by far the more significant factor.* |
| Вывод | *On balance, … · All things considered, … · Ultimately, …* |

## Типичные ошибки

- **Обсуждены все три пункта** — текст становится поверхностным, а заключение размытым.
- **Нет выбора в заключении.** Фраза *both are important* — не ответ на вопрос «какой эффективнее».
- **Инверсия без вспомогательного глагола**: ~~Not only it helps…~~ → *Not only **does it** help…*
- **Перегруз инверсией**: три *Never have I…* подряд звучат искусственно. Одна-две на эссе.
- **Риторический вопрос без ответа**: задал — сразу ответь в следующем предложении.
- **Разговорный регистр**: ~~kids, a lot of, stuff, I reckon~~ → *children, a great deal of, aspects, I would argue*.
- **Двойное отрицание в длинных предложениях**: ~~Schools don't hardly encourage…~~ → *Schools **rarely** encourage…*
