В первом уроке модуля зависимые предлоги промелькнули одной таблицей. Но именно они дают больше всего ошибок в Use of English: Part 1 и Part 2 почти в каждом тексте проверяют *access **to**, the key **to**, a lack **of***, а Part 4 любит превращать глагол в существительное (*They demanded higher pay* → *There was a **demand for** higher pay*). Логики «по переводу» здесь нет: по-русски мы «влияем **на**», «обсуждаем» без предлога и «отвечаем **на** письмо», а по-английски *affect* — без предлога, *discuss* — без предлога, *reply* — с **to**, а *answer* — снова без. Поэтому предлог учим вместе со словом, как часть слова.

## 1. Глагол без предлога, существительное — с предлогом

Самая коварная пара для C1: глагол переходный (дополнение сразу после него), а образованное от него существительное требует предлога.

| Глагол (без предлога) | Существительное + предлог |
|---|---|
| *discuss the plan* | *a discussion **of / about** the plan* |
| *emphasise quality* | *an emphasis **on** quality* |
| *demand / request better pay* | *a demand / request **for** better pay* |
| *attack the policy* | *an attack **on** the policy* |
| *affect / influence sales* | *an effect / influence **on** sales* |
| *approach the problem* | *an approach **to** the problem* |
| *access the data* | *access **to** the data* |
| *need more staff* | *a need **for** more staff* |
| *enter the market* | *entry **into** the market* |
| *answer the letter* | *an answer **to** the letter* (и *reply **to*** — у глагола тоже) |

> **Типичная ошибка русскоговорящих:** ~~discuss about~~, ~~emphasise on~~, ~~enter into the room~~, ~~approach to the door~~. Русское управление «обсуждать **о**», «подчеркнуть **на**» тут ни при чём: у глагола предлога нет. Но как только появляется существительное, предлог возвращается: *a **discussion about** costs*, ***emphasis on** costs*.

Ещё несколько существительных, у которых предлог нужно просто запомнить:

- **to**: *the key / solution / answer / alternative / threat / damage / reaction / attitude **to***. Русское «ключ **от**», «решение **проблемы**», «угроза **для**» сбивают: *the solution **to** the problem*, не ~~of the problem~~.
- **in**: *an increase / rise / fall / decline / change **in** something* — что именно изменилось: *a rise **in** prices*. А **of** — на сколько: *a rise **of** 5%*.
- **for**: *a reason / demand / need / responsibility / admiration / respect **for***.
- **with**: *a problem / connection / contact / relationship **with***; *a relationship **between** A and B*.

## 2. Глагол + дополнение + предлог

Здесь у глагола два дополнения: человек и то, в чём его обвиняют, от чего защищают, чем снабжают. Предлог идёт перед вторым.

| Предлог | Глаголы |
|---|---|
| **of** | *accuse, suspect, rob, deprive, remind, inform, convince **sb of** sth* |
| **for** | *blame, criticise, praise, thank, forgive, punish **sb for** sth* |
| **from** | *prevent, stop, discourage, prohibit, protect, distinguish **sb / sth from*** |
| **with** | *provide, supply, present, charge, credit **sb with** sth* |
| **on** | *congratulate, compliment **sb on** sth*; *blame sth **on** sb* |
| **into** | *translate, convert, divide, talk / persuade **sb into** (doing) sth* |

*blame* работает в обе стороны: *They **blamed** the manager **for** the delay = They **blamed** the delay **on** the manager.* Так же *provide **sb with** sth* = *provide **sth for / to** sb*.

> **C1 Part 4:** такие глаголы — готовые трансформации: *“You took the money!” she said* → *She **accused him of taking** the money*; *Because of the fog, the plane couldn't land* → *The fog **prevented the plane from landing***. После предлога — **-ing**.

## 3. Один корень — разные предлоги, разный смысл

Если предлог меняется, меняется и значение. Это любимая ловушка choice-заданий, где все варианты грамматичны.

| Сочетание | Значение | Пример |
|---|---|---|
| *concerned **about*** | обеспокоен | *Residents are **concerned about** the noise.* |
| *concerned **with*** | посвящён, занимается | *The report is **concerned with** long-term trends.* |
| *responsible **for*** sth | отвечает за что-то | *She's **responsible for** recruitment.* |
| *responsible **to*** sb | подотчётен кому-то | *The board is **responsible to** shareholders.* |
| *agree **with*** sb / an opinion | согласен | *I **agree with** you.* |
| *agree **to*** a proposal | дать согласие | *They **agreed to** our terms.* |
| *agree **on*** a point | договориться о | *We **agreed on** a date.* |
| *result **in*** | приводить к (следствие) | *The cuts **resulted in** delays.* |
| *result **from*** | быть следствием | *The delays **resulted from** the cuts.* |
| *consist **of*** | состоять из | *The panel **consists of** five experts.* |
| *consist **in*** (формально) | заключаться в | *Its value **consists in** its simplicity.* |
| *good **at*** / ***for*** / ***to*** / ***with*** | умелый / полезный / добрый к / ладит с | *good **at** maths, good **for** you, good **to** me, good **with** children* |
| *care **about*** / ***for*** | быть небезразличным / ухаживать (или любить) | *She **cares about** the environment. He **cares for** his elderly father.* |

> **Типичная ошибка русскоговорящих:** «уровень безработицы вырос **на** 2%» → ~~increased on 2%~~. Величина изменения — **by**: *Unemployment **rose by** 2%*, а у существительного — **of**: *a rise **of** 2%*. Итоговая точка — **to**: *rose **to** 7%*.

## 4. to — предлог, а не частица инфинитива

После некоторых слов *to* — обычный предлог, и после него идёт существительное или **-ing**, а не голый глагол:

*look forward **to**, object **to**, be / get used **to**, be committed **to**, be opposed **to**, be devoted **to**, with a view **to**, when it comes **to**, the key **to**, an alternative **to**, adjust **to**, contribute **to***.

- *We are **committed to reducing** emissions* (не ~~to reduce~~).
- *They bought the building **with a view to converting** it into flats.*
- *When it comes **to choosing** a supplier, price isn't everything.*

Проверка: если после *to* можно поставить существительное (*I object **to** the noise*), значит это предлог и глагол нужен с **-ing**.

## 5. Составные предлоги формального стиля

| Разговорно | Формально |
|---|---|
| *about* | ***with regard to**, **regarding**, **in terms of*** (в аспекте) |
| *because of* | ***owing to**, **on account of**, **in the light of*** (с учётом) |
| *following the rules* | ***in accordance with** / **in line with** the rules* |
| *for (someone)* | ***on behalf of*** (от имени) |
| *for (an idea)* | ***in favour of*** |
| *disagreeing with* | ***at odds with**, **in conflict with*** |
| *using* | ***by means of*** |

Внутри такого предлога ничего менять нельзя: ~~in accordance to~~, ~~with regards of~~, ~~on the behalf of~~. Разница *in charge of* и *in the charge of*: *She's **in charge of** the project* (руководит), *The children were left **in the charge of** a nanny* (под присмотром).

## Проверь себя

```quiz
q: "The committee is not ___ the details of the budget; it only sets overall priorities."
options: ["concerned about", "concerned with", "concerned for"]
answer: 1
explain: "**concerned with** — «занимается, имеет отношение к». *concerned about / for* значит «обеспокоен», а комитет здесь не волнуется, а просто не занимается деталями."
```

```quiz
q: "Which sentence is correct?"
options: ["We discussed about the new emphasis to security.", "We discussed the new emphasis on security.", "We discussed the new emphasis of security."]
answer: 1
explain: "У глагола **discuss** предлога нет, у существительного **emphasis** — предлог **on**."
```
