Part 3 в C1 Advanced устроена так же, как в B2 First: текст, восемь пропусков, справа слово капсом. Но слова сложнее. На B2 из *DECIDE* достаточно было сделать *decision*. На C1 из *COMPARE* нужно получить *incomparably*, из *ACKNOWLEDGE* — *unacknowledged*, а из *STAND* — *outstanding*. Типичный пропуск C1 требует **двух-трёх изменений сразу**: приставка + суффикс + множественное число или наречие. Один балл даётся только за полностью верное слово, включая орфографию.

## 1. Алгоритм для каждого пропуска

1. **Часть речи** — по месту в предложении (как на B2).
2. **Число**: нет артикля перед исчисляемым существительным, глагол во множественном → *-s*.
3. **Знак**: смысл требует отрицания? Ищи сигналы — *but, despite, sadly, criticised, failed*.
4. **Изменение корня**: *maintain → maintenance, pronounce → pronunciation, deep → depth, sustain → sustenance*.
5. **Орфография**: удвоение, *-y → -i*, выпадение *-e*.

## 2. Цепочки суффиксов

C1 любит слова, где к корню добавлено два-три суффикса:

| Корень | Цепочка | Результат |
|---|---|---|
| *nation* | -al → -ist → -ic | *nationalistic* |
| *sense* | -itive → -ity (+ in-) | *insensitivity* |
| *condition* | -al → -ly | *unconditionally* (+ приставка) |
| *industry* | -al → -ise → -ation | *industrialisation* |
| *rely* | -able → -ity | *reliability* |
| *person* | -al → -ise → -ed | *personalised* |
| *apply* | -cable → -ity | *applicability* |
| *occasion* | -al → -ly | *occasionally* |
| *method* | -ic → -al → -ly | *methodically* |
| *contradict* | -ion / -ory | *contradiction, contradictory* |

## 3. Отрицательные приставки — какая к какому слову

| Приставка | Когда | Примеры |
|---|---|---|
| **un-** | самая частая, особенно с *-able, -ed, -ing, -ful* | *unprecedented, unforeseen, unwavering, unaccountable, unremarkable* |
| **in-** | латинские корни | *inconclusive, insufficient, inadequate, indispensable, inconceivable* |
| **im-** | перед *p, m, b* | *impartial, immeasurable, imperceptible, immaterial* |
| **il-** | перед *l* | *illegible, illegitimate, illogical* |
| **ir-** | перед *r* | *irreversible, irrelevant, irreplaceable, irreproachable* |
| **dis-** | глаголы, существительные, часть прилагательных | *disproportionate, discontinue, disillusioned, disinclined* |
| **mis-** | «неправильно» | *misconception, misinterpret, misguided, mismanagement* |
| **non-** | «не являющийся» (часто через дефис) | *non-existent, non-committal, non-negotiable* |

Другие важные приставки: *over-* / *under-* (*overestimate, underrated*), *counter-* (*counterproductive*), *out-* (*outnumber, outweigh*), *re-* (*reassess*), *mal-* (*malfunction, malpractice*).

> **Ловушка:** *disinterested* — «беспристрастный», а не «незаинтересованный» (*uninterested*). *inflammable* = *flammable* («горючий»), это не отрицание. *invaluable* — «бесценный», а не «не имеющий ценности».

## 4. Отрицательный смысл без приставки

Иногда отрицание делают суффиксом *-less*: *relentless, pointless, flawless, effortless, countless*. А иногда смысл противоположен ожиданию: *priceless* — «бесценный», *harmless* — «безвредный».

## 5. Изменения корня, которые ломают баллы

| Слово | Производное |
|---|---|
| *maintain* | *maintenance* |
| *pronounce* | *pronunciation* |
| *repeat* | *repetition, repetitive* |
| *explain* | *explanation, explanatory* |
| *deceive* | *deception, deceptive, deceit* |
| *comply* | *compliance, compliant* |
| *suffice* | *sufficient, sufficiency, insufficiently* |
| *vary* | *variety, variable, variation, invariably* |
| *persuade* | *persuasion, persuasive* |
| *deny* | *denial, undeniable, undeniably* |
| *justify* | *justification, justifiable, unjustifiably* |
| *sympathy* | *sympathetic, sympathise, unsympathetic* |
| *strategy* | *strategic, strategically* |
| *argue* | *argument, arguably, argumentative* |
| *apology* | *apologetic, apologetically* |

> **Орфография:** *argue → argument* (без *e*), *true → truly*, *due → duly*, *whole → wholly*, *-ic → -ically* (*dramatically*, но *publicly*).

## Проверь себя

```quiz
q: "The jury found the evidence ___ (CONCLUDE) and the case was dropped."
options: ["unconcluded", "inconclusive", "nonconclusive", "conclusionless"]
answer: 1
explain: "Нужно прилагательное с отрицательным смыслом. От *conclude* — *conclusive*, отрицание с латинским корнем — **inconclusive**."
```

```quiz
q: "Her contribution to the project was ___ (VALUE): we could not have done it without her."
options: ["valueless", "invaluable", "unvaluable", "devalued"]
answer: 1
explain: "**invaluable** — «бесценный, неоценимый» (это не отрицание!). *valueless* значит «ничего не стоящий» — противоположный смысл."
```
