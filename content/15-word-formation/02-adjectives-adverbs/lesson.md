Примерно половина пропусков в B2 First Part 3 — прилагательные и наречия. Обычно они образуются от существительного или глагола: *danger → dangerous → dangerously*, *rely → reliable → reliably*. Главная трудность — выбрать **правильный** суффикс (*economic* или *economical*? *sensible* или *sensitive*?) и не забыть орфографию.

## Суффиксы прилагательных

| Суффикс | Значение | Примеры |
|---|---|---|
| **-ful** | полный чего-то | *use → useful, care → careful, success → successful, peace → peaceful, stress → stressful* |
| **-less** | без чего-то | *use → useless, care → careless, home → homeless, hope → hopeless, end → endless* |
| **-able / -ible** | можно сделать | *rely → reliable, afford → affordable, drink → drinkable, access → accessible, sense → sensible* |
| **-ive / -ative** | склонный к, делающий | *create → creative, attract → attractive, effect → effective, inform → informative* |
| **-ous / -ious** | обладающий качеством | *danger → dangerous, fame → famous, ambition → ambitious, mystery → mysterious* |
| **-al / -ial** | относящийся к | *nation → national, nature → natural, tradition → traditional, finance → financial* |
| **-ic / -ical** | относящийся к | *science → scientific, drama → dramatic, energy → energetic, history → historical* |
| **-y** | с чем-то, похожий | *sun → sunny, health → healthy, noise → noisy, salt → salty, risk → risky* |
| **-ish** | примерно, -оватый | *child → childish, fool → foolish, red → reddish* |
| **-ly** | (от существительных) | *friend → friendly, cost → costly, love → lovely* — это прилагательные! |

### -ful и -less: не всегда пара

- *careful / careless, useful / useless, harmful / harmless, painful / painless* — противоположности.
- ***helpful*** — готовый помочь; ***helpless*** — беспомощный (а не «неготовый помочь»; это *unhelpful*).
- ***priceless*** = бесценный, очень дорогой; ***worthless*** = ничего не стоящий. Ловушка: *-less* здесь не значит «дешёвый».
- *-ful* пишется с **одной** *l*: ~~beautifull~~, ~~successfull~~. Наречие — с двумя: *beautifully*.

### -able или -ible?

*-able* — живой суффикс, его добавляют к целым словам: *read**able**, afford**able**, wash**able**, comfort**able***. *-ible* — в основном к латинским корням, проще запомнить: *possible, visible, responsible, flexible, terrible, sensible, incredible, accessible*. Если у слова выпадает *-e*: *believe → believ**able**, love → lov**able***, но *change → change**able*** (мягкое *g*).

## Слова-«близнецы», которые путают

| Слово 1 | Слово 2 |
|---|---|
| **economic** — экономический (*economic growth*) | **economical** — экономный (*an economical car*) |
| **historic** — исторически важный (*a historic day*) | **historical** — относящийся к истории (*historical documents*) |
| **sensible** — разумный (*a sensible decision*) | **sensitive** — чувствительный (*sensitive skin, a sensitive child*) |
| **classic** — классический, эталонный (*a classic film*) | **classical** — классический (о музыке, античности) |
| **industrial** — промышленный | **industrious** — трудолюбивый |
| **childish** — ребяческий (неодобр.) | **childlike** — детский, наивный (одобр.) |

> **Типичная ошибка русскоговорящих:** «*Он очень **симпатичный***» → ~~sympathetic~~. *sympathetic* — «сочувствующий»; «симпатичный» — *nice, pleasant, attractive*. Похожие ложные друзья: *sensible ≠ сенсибельный*, *actual ≠ актуальный* (*actual* = фактический; «актуальный» — *relevant, topical*).

## Наречия: -ly

Большинство наречий = прилагательное + **-ly**. Правила орфографии (вспомни модуль 14):

| Прилагательное | Правило | Наречие |
|---|---|---|
| careful, successful | просто + *-ly* (две *l*!) | carefully, successfully |
| easy, lucky, happy | *-y* → *-ily* | easily, luckily, happily |
| possible, terrible, comfortable | *-le* → *-ly* | possibly, terribly, comfortably |
| dramatic, basic, economic | *-ic* → *-ically* | dramatically, basically, economically |
| true, whole | исключения | truly, wholly |

В Part 3 часто нужно **наречие с приставкой**: *FORTUNATE → **unfortunately***, *EXPECT → **unexpectedly***, *AVOID → **unavoidably***. Такие слова обычно стоят в начале предложения через запятую или перед прилагательным: *an **unexpectedly** large bill*.

> **B2-уровень:** производные от **причастий** — *-ed / -ing*: *surprise → surprising / surprised → surprisingly*; *disappoint → disappointing → disappointingly*. *Surprisingly, nobody complained.* — частый ответ в Part 3.

## Проверь себя

```quiz
q: "You can't trust him — he's completely ___ (RELY)."
options: ["reliable", "unreliable", "reliant"]
answer: 1
explain: "*You can't trust him* → отрицательный смысл → **unreliable**. Две операции: суффикс *-able* и приставка *un-*."
```

```quiz
q: "This car is very ___ — it uses hardly any petrol."
options: ["economic", "economical", "economy"]
answer: 1
explain: "**economical** = экономный, расходующий мало. *economic* = относящийся к экономике (*economic crisis*)."
```
