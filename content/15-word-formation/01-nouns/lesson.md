В B2 First есть целая часть экзамена про словообразование — Use of English, **Part 3**. Дан текст из восьми пропусков, у каждого справа слово капсом: *DECIDE*. Нужно вписать его производное: *decision*, *decisive*, *undecided*… Правил «какой суффикс к какому корню» нет — это словарный запас. Но есть **система**: по месту в предложении понять, какая часть речи нужна, и знать типичные суффиксы. В русском всё то же самое (*решать → решение → решительный*), поэтому логика тебе знакома — нужно только набрать английские модели.

## Шаг 1. Какая часть речи нужна?

В английском одно и то же слово может быть разными частями речи: *I **work** here* (глагол) — *I'm at **work*** (существительное). Поэтому часть речи определяем **по месту**:

| Перед пропуском / вокруг | Нужно | Пример |
|---|---|---|
| артикль *a / an / the*, *my / his / their*, *this*, предлог | **существительное** | *the ___ of the bridge* → *construction* |
| прилагательное перед пропуском | **существительное** | *a long ___* → *discussion* |
| *be / become / seem / look* | **прилагательное** | *She seems very ___* → *confident* |
| *very / so / too / quite* + пропуск + существительное | **прилагательное** | *a very ___ idea* → *useful* |
| после глагола или его дополнения, «как?» | **наречие** | *He drove ___* → *carefully* |
| начало предложения + запятая | часто **наречие** | *___, it stopped raining.* → *Fortunately* |
| *to* / модальный глагол + пропуск | **глагол** | *We need to ___ the road* → *widen* |

### Ещё три вопроса к каждому пропуску

1. **Единственное или множественное?** *Many ___ (SCIENCE)* → *scientists*. Нет артикля перед исчисляемым — тоже сигнал множественного числа.
2. **Положительное или отрицательное?** Смысл всего предложения: *The staff were ___ (HELP) and rude* → *unhelpful*.
3. **Нужно ли менять корень?** *decide → decision*, *high → height*, *long → length*.

## Суффиксы существительных

### Действие или процесс (от глагола)

| Суффикс | Примеры |
|---|---|
| **-tion / -ation / -ition** | *inform → information, explain → explanation, compete → competition, prepare → preparation* |
| **-sion** | *decide → decision, discuss → discussion, permit → permission, extend → extension* |
| **-ment** | *develop → development, agree → agreement, employ → employment, achieve → achievement* |
| **-ance / -ence** | *appear → appearance, perform → performance, exist → existence, prefer → preference* |
| **-al** | *arrive → arrival, survive → survival, refuse → refusal, approve → approval* |
| **-ure** | *fail → failure, close → closure, press → pressure* |
| **-ing** | *build → building, meet → meeting, understand → understanding* |

### Качество или состояние (от прилагательного)

| Суффикс | Примеры |
|---|---|
| **-ness** | *kind → kindness, happy → happiness, aware → awareness, ill → illness* |
| **-ity / -ty** | *able → ability, possible → possibility, popular → popularity, generous → generosity, safe → safety* |
| **-ance / -ence** | *important → importance, patient → patience, confident → confidence, different → difference* |
| **-th** | *long → length, strong → strength, wide → width, deep → depth, true → truth, grow → growth* |
| **-dom** | *free → freedom, bored → boredom, wise → wisdom* |

### Люди

| Суффикс | Примеры |
|---|---|
| **-er / -or** | *teach → teacher, employ → employer, visit → visitor, direct → director* |
| **-ee** | *employ → employee* (тот, кого наняли), *interview → interviewee* |
| **-ist** | *science → scientist, journal → journalist, tour → tourist, art → artist* |
| **-ian** | *music → musician, politics → politician, library → librarian* |
| **-ant / -ent** | *assist → assistant, apply → applicant, study → student* |

### Отношения и периоды

- **-ship** — отношения, статус: *friendship, relationship, partnership, leadership, membership, citizenship*
- **-hood** — период или состояние: *childhood, adulthood, neighbourhood, parenthood*

> **Типичная ошибка русскоговорящих:** путать людей и области: *economy* (экономика страны) — *economics* (наука) — *economist* (экономист); *science — scientist*; *journalism — journalist*; *politics — politician — policy* (курс, политика компании). ~~She works as a journalism~~ → *as a **journalist***.

## Корень меняется — запоминай

| Глагол / прилагательное | Существительное |
|---|---|
| *high, deep, wide, long, strong* | *height, depth, width, length, strength* |
| *choose, lose, succeed, die* | *choice, loss, success, death* |
| *believe, prove, advise, behave* | *belief, proof, advice, behaviour* |
| *pronounce, repeat, describe, explain* | *pronunciation, repetition, description, explanation* |
| *know, speak, laugh, receive* | *knowledge, speech, laughter, receipt / reception* |
| *curious, generous, anxious, proud* | *curiosity, generosity, anxiety, pride* |

> **Ловушка орфографии:** *pronounce* → ***pronunciation*** (без *o*), *explain* → ***explanation*** (без *i*), *maintain* → ***maintenance***, *argue* → ***argument*** (без *e*).

> **B2-уровень:** в Part 3 часто нужны **две** операции сразу: корень + суффикс + приставка или + множественное число: *EMPLOY → unemployment*, *SCIENCE → scientists*, *ABLE → inability*. После того как вписал слово, перечитай предложение целиком.

## Проверь себя

```quiz
q: "The ___ (EMPLOY) were happy with the new bonus scheme."
options: ["employers", "employees", "employment"]
answer: 1
explain: "Бонусы получают работники — **employees** (-ee = тот, над кем совершают действие: кого наняли). *employers* — работодатели."
```

```quiz
q: "What's the ___ (LONG) of the river?"
options: ["longness", "length", "longitude"]
answer: 1
explain: "*long → **length***, как *strong → strength*, *wide → width*. Суффикс **-th** и изменённый корень."
```
